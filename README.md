# ✊✋✌️ Python Rock, Paper, Scissors Game

A lightweight, beginner-friendly console-based implementation of the classic **Rock, Paper, Scissors** game written in Python.

## 🚀 Features

* **Interactive Gameplay:** Play directly from your terminal or command line.
* **Input Validation:** Safely handles invalid choices (e.g., numbers outside the 0–2 range) and declares a loss.
* **Randomized Computer AI:** Uses Python's built-in `random` module to generate unpredictable computer choices.
* **Clean Logic:** Simple conditional statements to determine the winner based on standard game rules.

---

## 📋 Rules of the Game

* **Rock (0)** beats **Scissors (2)**
* **Scissors (2)** beats **Paper (1)**
* **Paper (1)** beats **Rock (0)**
* If both you and the computer choose the same option, the game is a **Draw**.

---

## 🛠️ Requirements

* Python 3.x installed on your machine.
